# DriveCANHUB

## 仕様

### 入力
電源（XT60）&CAN信号（XH2ピン）  

### 出力  
電源+CAN信号（XT30(2+2)）  

### コンセプト
配布されたワンタッチコネクタを使用しても問題はないが、専用コネクタを使用することで「配線の抜き差しが楽になる」「差し間違いの防止」などのメリットが得られる。
