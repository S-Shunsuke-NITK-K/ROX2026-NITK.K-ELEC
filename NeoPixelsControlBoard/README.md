# NeoPixelsControlBoard
LEDテープを駆動するための電源を生成する基板

### 入力
12V電源（XT60 オス）&LED制御信号（XH2ピン オス）  

### 出力  
5V電源+LED制御信号（XH3ピン オス）  

### コンセプト
大量のLEDテープを安定動作させるため、DCDCコンバータ（BP5293-50）を用いて12V電源から5V電源を生成する。
