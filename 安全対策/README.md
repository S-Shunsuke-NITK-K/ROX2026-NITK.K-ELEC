## 安全対策①：ヒューズの容量選定
ヒューズとは、回路に異常な大電流が流れた際に回路を遮断し、機器や配線を保護する部品。

ヒューズ容量の選定が不適切な場合、本来切れるべきタイミングで溶断せず、回路を十分に保護できない可能性がある。

### 私たちが行ったヒューズの選定方法
①電流計（INA228）を用いて回路に流れる定常電流・突入電流を計測する。  
  
　私たちのロボットの場合  
　定常電流：10A〜13A  
　突入電流：最大37A  
　※「足回り」+「ボール投射機構」+「電装」が駆動している状態を定常状態と設定

②ヒューズのデータシートを参照する。  
　今回は、Littelfuse Inc製の"891 LP MINI® Series"のヒューズを使用することにした。  
　選定理由としては、定格電圧が58Vなので、今回使用する40Vバッテリーに対応しているため。  

　データシートから電流値-切断時間の表を見ると次の通りである。  
 
 <img width="374" height="676" alt="スクリーンショット 2026-09-10 21 55 23" src="https://github.com/user-attachments/assets/d4fdb111-437c-489a-ae1d-61042883cdab" />

　できる限り容量の小さいヒューズを選びたいということで最終的に15Aのヒューズを使用した。
 
　これまで、高専ロボコンなどでは問答無用でルールで使用できる限界値の30Aのヒューズを使用していた経験があるため、15Aのヒューズはすぐに切れてしまうと思っていたが、1度も切れることなく大会を終えることができた。

　**今大会の教訓：30Aのヒューズは思ってる以上に切れない！**

## 安全対策②：配線に識別シールの取り付け
全ての配線に対して、その用途や接続先が一目で分かるよう、テプラで作成した識別シールを貼り付けた。

これにより、配線の識別が容易になり、コネクタの差し間違い防止に繋がる。
