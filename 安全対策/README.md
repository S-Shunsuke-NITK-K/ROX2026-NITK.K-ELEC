## 安全対策①：ヒューズの容量選定
ヒューズとは、回路に異常な大電流が流れたときに、自ら切れて回路を保護する部品。

このヒューズの容量選定を適切に行っていないと、ヒューズが切れないといけないタイミングで適切に切れてくれない。

### 私たちが行ったヒューズの選定方法
①電流計（INA228）を用いて回路に流れる定常電流・突入電流を計測する。  
　私たちのロボットの場合  
　定常電流：10A〜13A  
　突入電流：最大37A  
　※「足回り」+「ボール投射機構」+「電装」が駆動している状態を定常状態と設定

②ヒューズのデータシートを参照する。  
　今回は、Littelfuse Inc製の"891 LP MINI® Series"のヒューズを使用することにした。
　選定理由としては、定格電圧が58Vなので、今回使用する40Vバッテリーに対応しているため。
